# Layout Templates

## Chart

Use this default hierarchy:

1. Cobalt header with `CHART X-X`, exact chart title, and small orbital motifs.
2. Main concept card containing the central formula/timeline and one strong illustration.
3. Two to four aligned teaching cards for uses, contrasts, forms, or exceptions.
4. Compact signal-word, contraction, or warning strip when needed.
5. Bottom takeaway strip with a lightbulb and one CCQ.

Prefer a comparison grid when two tenses or meanings are contrasted. Use equal columns and mirrored internal structure. A timeline must label the reference point and show whether an activity stops before, reaches, or surrounds it.

Charts normally produce PNG only.

## Exercise or drill

Use this default hierarchy:

1. Cobalt header with exact `EXERCISE N` title and chart scope.
2. One-line directions on a cream strip.
3. Optional story/topic plaque.
4. Question cards arranged in reading order: top-to-bottom, then left-to-right only when column separation is unmistakable.
5. Context illustration occupying 25–40% of the useful area.
6. Optional vocabulary note or process cue at the bottom.

Keep all blanks empty except a source-provided worked example. Do not visually emphasize a choice that would reveal the answer.

For long exercises, split into `EXERCISE 29A`, `EXERCISE 29B`, etc., while preserving source numbering.

## Pretest

- Use a prominent chapter/pretest header.
- Put directions in a separate card.
- Use one or two clean numbered columns, divided by a dotted or thin rule.
- Preserve chart-reference badges beside each item.
- Omit the answer key and any upside-down textbook key.
- Use only small thematic illustrations so the diagnostic items remain dominant.

## Listening exercise

- Add a headphones icon and clear sequence cue such as `FIRST COMPLETE • THEN LISTEN • FINALLY CHECK`.
- Keep the transcript or gaps on the left and a contextual illustration on the right when feasible.
- Number every blank visibly.
- Do not place a fake playable audio control in a static image.
- When an actual audio link or Drive ID is supplied, keep it in accompanying Markdown/code metadata, not printed as a raw ID on the worksheet.

## Answer key

- Render only when explicitly requested or supplied.
- Prefer high-contrast black/white or minimal cream/navy; illustration is optional and usually unnecessary.
- Keep exercise numbers and subitems aligned in a compact table/list.
- Never mix answers into the student worksheet.

## Source scan recreation

Do not mimic scan defects. Rebuild the instructional structure using the EF visual DNA. Preserve the visible source title inside the image even when the external filename uses a session prefix.
