# Quality Checklist

Approve only when all applicable checks pass.

## Style

- [ ] The image reads as an authored illustration at first glance.
- [ ] Black contour and hatch lines carry the form.
- [ ] Linework is smooth, consistent, and purposeful.
- [ ] No global grain, canvas, yellow, sepia, haze, or distressed-paper filter is visible.
- [ ] Broad surfaces are calm; texture appears only where it explains form or material.

## Color or monochrome

- [ ] Color mode retains visible black ink with transparent watercolor below it.
- [ ] Color is locally strong enough to read but remains matte and restrained.
- [ ] Monochrome mode contains no hidden color or gray wash; gray comes from line density.

## Subject

- [ ] People do not look photo-traced or airbrushed.
- [ ] Faces, hair, hands, anatomy, objects, and diagnostic animal features are plausible.
- [ ] Construction stages preserve geometry and include temporary supports only when appropriate.
- [ ] The teaching action or process is understandable within a few seconds.

## Text and facts

- [ ] Every required line is present, legible, and spelled exactly.
- [ ] Vietnamese accents are correct.
- [ ] No pseudo-text, extra labels, signature, or watermark appears.
- [ ] Niche factual or technical claims were checked when uncertain.

## Retry rule

Retry once for a single concrete defect. Name the defect and preserve all approved elements. If text or anatomy remains incorrect after the targeted retry, show the result and ask the user rather than broadening the redesign.
